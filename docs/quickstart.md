# 快速开始

下文以 **Windows** 为例。把发行包解压后的目录称为 `SERVER_HOME`（例如 `D:\openOntology`，该目录下应能看到 `bin` 文件夹）。

## 1. 安装 JDK 25 并设置 JAVA_HOME

本系统需要 **JDK 25 或更高**。装完后还须设置环境变量 `JAVA_HOME`（安装程序不一定会设）。

1. 打开 [Oracle JDK 下载页](https://www.oracle.com/java/technologies/downloads/)，选择 **JDK 25**、Windows，下载并按向导安装  
2. 记下安装目录（常见 `C:\Program Files\Java\jdk-25`，其下应有 `bin\java.exe`）  
3. 右键「此电脑」→「属性」→「高级系统设置」→「环境变量」，新建用户或系统变量：  
   - 变量名：`JAVA_HOME`  
   - 变量值：上面的 JDK 安装目录  

## 2. 启动

在资源管理器中打开 `D:\openOntology\bin`（改成你的解压目录），双击 `startup.bat`。会弹出一个黑色窗口，请保持打开。

浏览器打开：

```text
http://localhost:8825/
```

### 安装 / 卸载 Windows 服务（可选）

若希望开机自动运行、不长期开着黑色窗口，可把本系统装成 Windows 服务。在 `bin` 目录中**右键脚本 → 使用 PowerShell 运行**（会弹出 UAC）：

- `installService.ps1`：安装服务（服务名 `OpenOntology`，默认自动启动）
- `uninstallService.ps1`：卸载服务

装好后可在 Windows「服务」里启动、停止。卸载前请先停止该服务。不要同时用 `startup.bat` 和 Windows 服务跑两份实例。

## 3. 系统初始化（首次必做）

首次进入会跳到初始化页。先自动做基础初始化，再按向导配置大模型与业务域；两项都完成后进入系统，之后不会再进入本页。

![系统初始化](images/init.png)

**基础初始化**

页面中间会显示进度（内置工具 → 系统界面组件 → 算法库）。完成后自动进入下一步。

**配置大语言模型**（已有模型则跳过）

1. 提供商默认 **DeepSeek**（只需 API Key）。按页内说明打开 [DeepSeek 开放平台](https://platform.deepseek.com)，登录后创建密钥（这是调用大模型的密钥，不是软件 License），粘贴到表单  
2. 可先 **测试连接**，再 **保存并继续**  
3. 若用其它兼容接口，将提供商改为 **自定义**，填写名称、URL、API Key、模型名后再保存  

**配置业务域**（已有域则跳过）

域是一套业务数据空间（本体 + 业务库连接）。二选一（默认第一项）：

- **导入零售演示（推荐）**：系统创建演示域并导入零售样例，可马上在工作台试用。不必删除演示域，之后仍可在「设置 → 域管理」再建自己的业务域  
- **连接自己的业务库**：填写 JDBC 创建空域，之后在本体管理中自行建模  

完成后即可进入系统。若当前域还没有本体，切换域时会询问是否进入 **本体管理**（选「是」则跳转，选「否」则留在当前页）。

## 4. 试问

1. 顶栏确认已选中演示域（若选择了「连接自己的业务库」，请先在 **本体管理** 中建模或从库导入）  
2. 打开 **智能体工作台**  
3. 提问，例如：「哪些客户卖的比较好，为什么？」
